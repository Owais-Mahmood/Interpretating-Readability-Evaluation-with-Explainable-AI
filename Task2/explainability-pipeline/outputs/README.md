# Generated outputs

- `manifests/`: frozen run metadata.
- `predictions/`: model outputs.
- `explanations/`: raw and aligned explanation scores.
- `metrics/`: per-example and aggregate metrics.
- `statistics/`: confidence intervals, effects, and paired tests.
- `tables/`: publication-ready tables.
- `figures/`: plots and explanation visualisations.
- `errors/`: selected error-analysis records.
- `logs/`: execution logs.
